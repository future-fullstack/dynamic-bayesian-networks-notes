# 03 DBN、两时间片模板与展开

> 目标：能从初始分布和一步转移模板，写出任意有限长度的 DBN 联合分布。原书主线：§6.2.2。

## 1. DBN 是可重复展开的贝叶斯网络模板

PGM 把 DBN 定义为一对网络 $\langle B_0,B_{\to}\rangle$：

- $B_0$：初始时间片的 BN，规定初始变量的联合分布。
- $B_{\to}$：两时间片贝叶斯网络 2-TBN，规定下一片给定上一片的条件分布。

本库统一用 $t=1$ 为第一片；原书常从 0 开始。名称 $B_0$ 表示“初始网络”，不要求你把本库的索引全部改回 0。

DBN 中的 dynamic 指被建模的变量随时间演化。**不要求网络拓扑每一步改变**；常见 DBN 恰好反复使用同一结构与参数。

## 2. 两时间片模板怎样表示依赖

用 $X=(X_1,\ldots,X_n)$ 表示上一片，$X'=(X_1',\ldots,X_n')$ 表示下一片：

$$P(X'\mid X)=\prod_{i=1}^{n}P(X_i'\mid\mathrm{Pa}(X_i')).$$

父节点可以来自上一片，也可以来自下一片中排序更早的节点。2-TBN 的上一片节点作为已知条件，不在这个模板中重新给它们定义先验 CPD；它们的分布来自前一步。

**同片边 intra-slice**：$F_t\to Y_t$，当前故障影响当前报警。**跨片边 inter-slice**：$F_t\to F_{t+1}$，故障有时间持续性。**持续边 persistence edge** 是 $X_t\to X_{t+1}$ 这种跨片自变量的边，并非一个节点指向自己。

下一片内部必须无环，跨片边按时间向前，展开后才是 DAG。$A_t\to B_{t+1}$ 与 $B_t\to A_{t+1}$ 可以同时存在：这是跨时间反馈，不构成展开图里的有向环。

## 3. 展开 unrolling

把模板在 $1,2,\ldots,T$ 重复实例化：

$$P(X_{1:T})=P_{B_0}(X_1)\prod_{t=2}^{T}\prod_iP(X_{i,t}\mid\mathrm{Pa}(X_{i,t})).$$

注意：重复的是 CPD 的形式和参数；各时刻的随机变量仍是不同节点。$F_1$ 与 $F_2$ 不是同一个随机变量。

初始网络不能省略。例如设备第一天是新机还是旧机，决定第一天故障的先验概率。只给转移模型无法唯一确定完整序列分布。

## 4. 接口变量 interface variables

上一片中，直接影响下一片变量的节点组成前向接口。比如 $F_t$ 会影响 $F_{t+1}$，而一个只作叶节点的 $Y_t$ 不再影响未来，则接口只需包含 $F_t$。

准确过滤需要传递**接口上的联合后验**，而不一定要保存全部历史节点。历史观测的作用压缩进这个分布；这也是递推可以长期运行的原因。若多个接口变量存在相关性，仅传每个变量的单独概率通常不够。

## 5. 用一个多变量 DBN 看清因子化

设 $W_t$ 为工况，$F_t$ 为故障，$Y_t$ 为报警，选择：

$$P(W_t,F_t,Y_t\mid W_{t-1},F_{t-1},Y_{t-1})
=P(W_t\mid W_{t-1})P(F_t\mid F_{t-1},W_t)P(Y_t\mid F_t).$$

这明确假设：工况按自身历史变化；故障依赖上一故障和当前工况；报警给定当前故障后不再直接依赖历史报警。接口是上一片的 $W,F$。它是一个示范模型，是否适用于真实设备要靠领域知识和数据检查。

## 6. 常见模型在 DBN 家族里的位置

| 模型 | 结构特点 |
|---|---|
| Markov chain | 状态直接被观测，不另设隐状态观测层 |
| HMM | 一个离散隐状态链，加一个当前观测模型 |
| Factorial HMM | 多条状态链共同产生观测；即便先验链独立，看到共同观测后也会相关 |
| Coupled HMM | 多个状态过程的转移相互依赖 |
| Linear dynamical system | 连续状态、线性高斯转移和观测 |
| Switching dynamical system | 离散模式选择连续系统的动态规则 |

把所有状态分量合成一个巨大的变量，有限离散 DBN 原理上可以转成 HMM；但组合状态数会呈指数增长，失去结构化表示的优势。能转写不等于能高效计算。
