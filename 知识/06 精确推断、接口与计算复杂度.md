# 06 精确推断、接口与计算复杂度

> 目标：理解“图很稀疏”为什么仍可能算不动，知道精确推断在传递什么。对应 PGM §15.2，基础来自第9、10章。

## 1. 精确推断做的是因子运算

以求 $P(S_t\mid y_{1:t})$ 为例：固定观测，乘上相应 CPD，把非查询隐变量求和消去，最后归一化。直接枚举所有状态轨迹要处理约 $K^t$ 条路径，$K$ 为每片联合状态数。

Variable elimination（变量消元）把求和分配到乘积中，避免重复计算。例如：

$$\sum_a f(a,b)g(a,c)=h(b,c).$$

消去 $a$ 后产生新因子 $h(b,c)$，于是原本没直接连接的 $b,c$ 现在必须一起表示。**消元顺序决定中间因子有多大**，也决定实际开销。

## 2. 时间递推就是一种合适的消元顺序

先消去过去，只留下把过去与未来分开的接口 $I_t$，传递：

$$m_t(I_t)=P(I_t\mid y_{1:t}).$$

在普通 HMM 中接口就是一个状态变量。在多变量 DBN 中接口可能包含多个节点，消息通常是它们的联合分布。

未来给定接口后与更早过去分离，因此这条消息足以支持后续过滤。把旧片消掉不意味着历史证据被忘记，而是它已被压缩进消息。

## 3. 团树与模板团树

Junction tree / clique tree 把原变量组织成团，在团之间传递消息。它需要满足 running intersection：某变量出现在两个团中时，连接它们的路径上每个团也必须包含该变量。

DBN 可以预先建立两片的模板团树，反复加入旧接口消息、当前证据，校准后提取新接口消息。为了接收与输出完整接口联合分布，相应接口必须能被适当团容纳。

只对孤立 2-TBN 构造一棵小团树，未必就能支持长期精确过滤；旧的接口消息可能比原模板局部 CPD 大得多。这是时间推断比“一次两片计算”更难的原因之一。

## 4. Entanglement：观测让隐状态逐渐纠缠

这里的 entanglement 是概率依赖，并非量子纠缠。考虑两条独立的隐状态链 $A_t,B_t$ 共同产生 $Y_t$：

$$A_t\to Y_t\leftarrow B_t.$$

未观测 $Y_t$ 时，若无其他路径，两条链可能独立；一旦给定共同观测，碰撞点打开，两个隐状态的后验会相关。随着历史积累，这种相关性可能经跨片路径传播到更多状态分量。

因此，**生成模型的局部因子很小，不保证过滤后的联合信念也能保持同样的独立分解**。这是 PGM §15.2.4 的核心警告。它不是说所有 DBN 必然完全相关；特殊结构、观测模式和参数仍可能保留可利用的独立性。

## 5. 复杂度取决于状态维数与树宽

若接口含 $m$ 个各有 $r$ 种取值的变量，完整联合表有 $r^m$ 项。二十个二元变量就有 $2^{20}$ 个状态配置；局部 CPD 再简短，也不代表接口消息一定简短。

离散图精确消元的开销通常对 induced width / treewidth（诱导宽度／树宽）呈指数关系，对固定模板的序列长度则常可线性扩展。这里省略的常数可能已经非常大。

对 $K$ 状态、稠密转移矩阵的 HMM，过滤每步 $O(K^2)$，总时间 $O(TK^2)$，仅输出当前过滤分布时内存 $O(K)$。完整平滑通常还需保存前向信息，内存常为 $O(TK)$。稀疏转移可进一步节省运算。

## 6. 什么时候值得做精确推断

状态少、接口小或有特殊结构时，精确算法透明、稳定，也适合当近似方法的参照。不要一看到 DBN 就直接上粒子滤波。

连续变量也不是一律不能精确推断：线性高斯模型的分布对运算封闭，可以用均值和协方差精确表示，见 [[10 连续状态、Kalman与混合DBN]]。
