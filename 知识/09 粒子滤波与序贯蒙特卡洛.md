# 09 粒子滤波与序贯蒙特卡洛

> 目标：理解粒子、权重和重采样，知道为什么“多采样”仍可能失败。对应 PGM §15.3.3。

## 1. 一个粒子是一种状态假设

用 $M$ 个状态样本及其归一化权重表示信念：

$$b_t(s)\approx\sum_{m=1}^{M}w_t^{(m)}\delta_{s_t^{(m)}}(s),\quad\sum_mw_t^{(m)}=1.$$

$\delta$ 表示放在粒子位置的点质量。粒子不是一台真实设备，而是“当前状态可能是什么”的一个假设。对状态函数 $h$，后验期望近似为 $\sum_mw_t^{(m)}h(s_t^{(m)})$。

它用有限样本避免存完整状态表。离散、连续与混合状态都可使用，但效果取决于提议分布是否能把样本放到有后验质量的区域。

## 2. Bootstrap particle filter 的基本循环

为清楚起见，以下采用“更新后按需重采样”的约定。

1. **初始化**：采 $s_1^{(m)}\sim P(S_1)$，赋未归一化权重 $\tilde w_1^{(m)}=P(y_1\mid s_1^{(m)})$，归一化。
2. **传播**：由每个旧粒子采 $s_t^{(m)}\sim P(S_t\mid s_{t-1}^{(m)})$。
3. **加权**：$\tilde w_t^{(m)}=w_{t-1}^{(m)}P(y_t\mid s_t^{(m)})$。
4. **归一化**：$w_t^{(m)}=\tilde w_t^{(m)}/\sum_r\tilde w_t^{(r)}$。
5. **必要时重采样**：按当前权重抽取 $M$ 个粒子作为下一轮祖先，允许重复，之后权重重置为 $1/M$。

可以在重采样前计算当前的加权期望；重采样后的等权样本也近似同一目标，但额外引入抽样噪声。另一类实现把重采样放在下一轮开头，两者不要混写权重公式。

## 3. 权重来自重要性采样，不是随便打分

若从更一般的提议分布 $q_t(s_t\mid s_{t-1},y_t)$ 采样，则：

$$\tilde w_t^{(m)}=w_{t-1}^{(m)}
\frac{P(y_t\mid s_t^{(m)})P(s_t^{(m)}\mid s_{t-1}^{(m)})}
{q_t(s_t^{(m)}\mid s_{t-1}^{(m)},y_t)}.$$

分子是目标模型给这次扩展的概率，分母修正我们实际采样方式造成的偏差。Bootstrap 方法选择转移模型作为 $q_t$，于是转移项约掉，只剩观测似然。

提议分布必须在目标有质量的区域提供支持。若所有粒子都落在观测几乎不可能出现的区域，重采样也无法凭空创造缺失状态；可考虑让提议显式利用当前观测。

## 4. 为什么单纯累计权重会退化

长序列不断乘观测似然后，通常少数粒子占据几乎全部权重，其他样本贡献近零。这叫 weight degeneracy。一个常用诊断量是：

$$\mathrm{ESS}=\frac{1}{\sum_m(w_t^{(m)})^2}.$$

权重相同则 ESS 为 $M$；只有一个粒子有权重时接近 1。ESS 是权重分散程度的启发式指标，不是严格意义上“有多少独立正确样本”。若粒子几乎全是相同状态，权重相同也不能说明多样性足够。

可以在 ESS 低于阈值（例如 $M/2$，只是常见选择）时重采样。阈值应随实验调整，没有通用最优值。

## 5. 重采样解决了什么，又造成什么

它把运算资源集中到更有解释力的区域，减缓权重塌缩。常见 multinomial、stratified、systematic 等方案有不同方差与实现特性。

但它会复制粒子、删除候选，造成 sample impoverishment（样本贫化）。转移噪声很小时，复制后也难以重新分散。若保存整条祖先轨迹，长期会出现 path degeneracy：当前粒子可能都来自很少几个早期祖先，因此历史平滑质量差。

改善方向包括：更好的提议、适当增加粒子数、重采样后使用保持目标分布的 MCMC 更新，以及专门的粒子平滑方法。随便给粒子加噪声会改变目标，除非明确作为模型或算法的一部分处理。

## 6. Rao–Blackwellized / collapsed particle filtering

把状态分成需要采样的 $Z_t$ 与给定采样历史后能解析处理的 $X_t$：

$$P(X_t,Z_{1:t}\mid y_{1:t})
=P(X_t\mid Z_{1:t},y_{1:t})P(Z_{1:t}\mid y_{1:t}).$$

粒子只采 $Z$，每个粒子内部维护 $X$ 的条件分布。例如离散工况用粒子表示，给定工况路径后连续位置可以用 Kalman filter 更新。权重需要用解析部分积分得到的观测预测似然，而不是随便取一个连续状态值。

好处是减少采样维度和相关估计的方差；代价是每个粒子的解析更新更贵，而且条件子问题必须真的可处理。它不是“所有混合 DBN 都能高效分解”的保证。

## 7. 必做的正确性检查

小模型先与精确过滤对照；逐步记录权重总和、ESS、状态多样性与误差；比较多个随机种子及不同粒子数。只看一条“平滑得很好看”的曲线不够。

连续观测用密度作权重；长序列权重尽量在对数空间更新。所有权重为零时，应诊断观测异常、提议支持或数值下溢，不能默默改成均匀权重后宣称正常。
